# AutoTask 架构设计

> 版本: v1.0 | 日期: 2026-05-14 | 状态: 规划中

---

## 一、项目愿景

**AutoTask = 企业级任务编排 + 项目管理 + AI 原生复杂任务框架**

通过整合 TaskSystem、TaskMachine、ProposalOS、ProjectOS、Cultivating 五个模块，构建一个**零外部依赖、可独立部署**的任务编排与项目管理框架。

---

## 二、整合模块分析

### 2.1 来源模块概览

| 原模块 | 源路径 | 核心功能 | 提取价值 |
|--------|--------|----------|----------|
| TaskSystem | `System/core/task_system/` | 任务调度引擎 | UnifiedGateway、优先级队列、重试引擎 |
| TaskMachine | `System/core/task/` | 状态机 + 执行器 | ~~TaskMachine~~ → **StateMachine + ExecutorFactory** |
| ProposalOS | `ProposalOS/` | 方案生命周期管理 | 5层架构、评审总线、知识中枢 |
| ProjectOS | `ProjectOS/` | 项目管理框架 | WBS分解、风险管理、质量管理 |
| Cultivating | `Cultivating/` | 目标规划/进度追踪 | Goal分解、Milestone、进度追踪 |

## 六、关键设计决策

### 6.1 双链路解耦

- **TaskChain**: 专注于任务的**执行**，从提交到完成的完整生命周期
- **GoalChain**: 专注于目标的**规划**，从定义到评审的完整生命周期
- **ProjectContext**: 连接两条链路，提供项目维度的**聚合视图**

### 6.2 事件驱动架构

```
所有模块通过 UnifiedEventBus 通信，实现完全解耦：

    TaskChain ──► EventBus ◄── GoalChain
                        │
                        ◄── ProjectContext
```

### 6.3 存储抽象

支持 SQLite（默认）/ MySQL / PostgreSQL，通过 Repository Pattern 统一访问。
